# Требования: volleyball-coach-assistant

Черновик. Продиктовано тренером, дополняется по ходу обсуждения.

## Что это

Веб-приложение для тренера волейбольной команды: расстановка стартового состава,
ведение статистики матча вживую и короткая итоговая сводка.

## Общие принципы

- Статический SPA на Vue 3, **без бэкенда**. Открывается по ссылке, без входа и пароля.
- Данные хранятся **локально в браузере**. У каждого, кто откроет ссылку, — свои данные;
  чужую статистику по ссылке не увидеть.
- Обмен результатами — через PDF: печать итогового экрана средствами браузера
  либо генерация PDF-файла на фронтенде.
- Приложение пока только для одной команды.

## Состав команды

Захардкожен в приложении. Редактирования состава в UI нет.

Поля игрока: имя, фамилия, ID, игровой номер, роль.

Роли: центральный блокирующий (ЦБ), доигровщик, связка, диагональный, либеро.

## Экран 1. Расстановка (стартовый состав)

- Площадка разделена на зоны, как в волейболе.
- Тап по зоне → появляется список игроков → тап по игроку → игрок назначен в зону.
- Роль игрока можно переопределить с дефолтной на другую прямо при назначении.
- Дефолтная основа (стартовая шестёрка) подставляется сразу; её можно перебить.
- Опционально назначается либеро — если он в команде есть.

### Валидация

- Не больше двух ЦБ.
- Не больше двух доигровщиков.
- Если есть диагональный — связка одна.
- Если диагонального нет — связок может быть две.

## Экран 2. Настройка игры

- Название команды соперника (текстовое поле).
- Кто подаёт первым: мы или они.
- Кнопка «Начать игру» — переход к ведению матча.

## Экран 3. Ведение матча

### Счёт

- Сверху кликабельный текущий счёт; подающая команда подсвечивается.
- Клик по счёту → +1 очко.
- Можно отменить добавленное очко, если нажал по ошибке.
- Партия идёт до 25 очков с разницей +2; решающая (пятая) — до 15.
- Матч — максимум 5 партий, играем до трёх побед.
- Ведётся история набора очков: сколько подряд набрала каждая команда
  (например, соперник 3 подряд, затем мы 2, и так далее).

### Площадка

- Под счётом поле с расстановкой. Отображаются только наши игроки.
- Два режима отображения, переключаются **вручную**:
  - **протокольный** — игроки стоят по зонам протокола;
  - **игровой** — реальная расстановка со смещениями, нужна для расстановки на приёме.
- В кружке игрока — его игровой номер и роль.
- Ротация автоматическая: когда подача переходит к нам, игроки переставляются сами.
  Ручного переключателя расстановки 1–6 нет.
- Из фаз интересует только **приём**. Фаз подачи, защиты и атаки у нас нет.

### Статистика по игроку

Клик по игроку открывает небольшое меню добавления статистики. Считаем только
количество фактов — без оценок качества и без зон:

- +очко
- +подача
- +ошибка на подаче
- +общая ошибка
- +блок

### Замены

- На игровом экране партии доступны замены игроков.
- Замены валидируются по правилам волейбола — точные правила надо зафиксировать.

## Либеро

- Назначается опционально на экране 1, если он в команде есть.
- Если назначен: на игровом экране автоматически занимает место ЦБ
  на задней линии после того, как ЦБ потерял подачу.

## Между партиями и итоги матча

- После каждой партии начинаем заново — условно с первого экрана (расстановка).
- Статистика каждого игрока в новой партии считается с нуля.
- Когда матч заканчивается, показывается:
  1. статистика по каждой партии отдельно;
  2. суммарная статистика по каждому игроку за весь матч.
- Итог печатается средствами браузера или сохраняется в PDF.

## Референс: Volley51 (app.volley51.ru)

Тренер показал как пример отображения площадки. Что там есть:

- Статический сайт/PWA на чистом HTML/CSS/JS, гайд по схеме 5-1.
- Площадка с семью фишками игроков: СВ, ДИ, Ц1, Ц2, Д1, Д2, ЛБ. На фишке —
  номер позиции по протоколу.
- Переключатель расстановки 1–6 (все расстановки схемы 5-1).
- Фазы: ПОДАЧА / ЗАЩИТА / АТАКА / ПРИЕМ — под каждую фазу свои позиции.
- Переключатель «При подаче / на приёме». Появляется только в расстановках 1, 5, 2
  и только в фазах ЗАЩИТА/АТАКА. Меняет местами Д1 и ДИ (расстановка 1) либо выводит
  на площадку либеро вместо Ц1/Ц2, отправляя ЦБ на скамейку (расстановки 5 и 2).
- Скамейка: игрок (либеро или ЦБ) ставится за границей площадки справа.
- Настройки: «Сперва расстановка по протоколу» — сначала на секунду показывается
  протокольная расстановка, затем анимация в игровую; «Номера позиций» — вкл/выкл
  номера на фишках.
- Есть i18n, манифест (ставится как приложение).

### Что берём оттуда

- Координаты расположения игроков — как основа для дефолтной расстановки.
- Визуальный язык площадки в целом.
- Пару «протокольная / игровая расстановка», но у нас переключение **ручное**,
  а не автоматическое, как у них.

### Что не берём

- Фазы ПОДАЧА / ЗАЩИТА / АТАКА — нужна только фаза приёма.
- Ручной переключатель расстановок 1–6 — у нас ротация автоматическая.
- Номера позиций на фишках — у нас в кружке игровой номер и роль.
