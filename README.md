# volleyball-coach-assistant

**Помощник тренера по волейболу:** расстановка стартового состава, ведение
матча и статистика вживую — в браузере, без регистрации и установки.

**Приложение:** <https://volleyhelper.vzhurbenko.com/>

Статический SPA на Vue 3, **без бэкенда**: открывается по ссылке, без входа
и пароля. Данные хранятся локально в браузере — у каждого, кто откроет
ссылку, свои. Обмен результатами — печатью итогового экрана средствами
браузера.

## Возможности

**Состав команды**

- добавление, изменение и удаление игроков: имя, фамилия, игровой номер, роль;
- дефолтная стартовая шестёрка и название команды;
- экспорт и импорт состава через JSON — чтобы перенести команду на другое
  устройство;
- при первом запуске состав пустой: команду набирают вручную или импортом.

**Расстановка**

- площадка с шестью зонами, назначение игроков тапом по зоне;
- роль игрока можно переопределить прямо при назначении;
- проверки по правилам: не больше двух ЦБ и двух доигровщиков, одна связка
  при диагональном;
- опциональный либеро;
- пока шестёрка не заполнена и роли не сходятся, игра не начнётся.

**Матч**

- табло с подачей, отменой очка и сериями очков;
- партии до 25 очков (пятая — до 15), матч до трёх побед;
- автоматическая ротация при переходе подачи;
- протокольная и игровая площадка; игровой режим — координаты приёма
  для шести расстановок;
- статистика игрока: очко, подача, ошибка на подаче, общая ошибка, блок;
- замены по FIVB 2025–2028: 6 замен в партии, фиксированные пары, возврат
  на прежнюю позицию один раз; либо режим «только количество» для
  любительской лиги;
- либеро выходит вместо ЦБ задней линии.

**Между партиями и итоги**

- шестёрка предзаполнена, подача чередуется по FIVB, перед пятой партией
  тренер выбирает подающую команду;
- статистика по партиям и сумма за матч, серии, исключительные замены;
- печать итогового экрана и «Новая игра».

**Сохранение**

- текущий матч, состав и стартовая шестёрка сохраняются в `localStorage`;
- перезагрузка страницы возвращает матч в том же состоянии.

## Как устроено

Ядро в `src/domain/` не знает про Vue: это чистые функции над состоянием,
поэтому правила волейбола покрыты обычными unit-тестами и не зависят
от интерфейса.

Журнал событий — источник истины: счёт, подача, ротация, состав на площадке,
серии и статистика выводятся из него. Отмена очка — удаление события
и пересчёт, а перезагрузка страницы восстанавливает матч как был.

| Модуль                               | Отвечает за                          |
| ------------------------------------ | ------------------------------------ |
| `constants.js`, `players.js`         | роли, зоны, лимиты, поиск по составу |
| `roster.js`, `lineup.js`             | состав и стартовая расстановка       |
| `score.js`, `streaks.js`, `match.js` | счёт, серии и журнал событий         |
| `rotation.js`, `formations.js`       | ротация и координаты приёма          |
| `substitutions.js`, `libero.js`      | замены и либеро                      |
| `stats.js`, `storage.js`             | статистика и `localStorage`          |

## Разработка

```sh
npm install
npm run dev          # дев-сервер с горячей перезагрузкой
npm run test:unit    # тесты (Vitest)
npm run lint         # oxlint + ESLint
npm run build        # сборка в dist/
```

Тесты гоняются в watch-режиме; разовый прогон — `npm run test:unit -- --run`.

Работа идёт по одному issue: ветка от `master` → PR → CI (lint, тесты, сборка) →
merge. Из `master` собирается и деплоится статика, уведомление о деплое уходит
в Telegram.

## Структура

```
src/
├── domain/      ядро: правила волейбола, без Vue
├── stores/      Pinia: расстановка и текущий матч
├── components/  площадка, табло, диалоги
├── views/       экраны
├── router/      маршруты и гварды
├── storage.js   сохранение текущего матча
└── main.js
```
